幼兒園圖書借閱系統 使用說明
================================

【下載與解壓縮】
1. 從 GitHub 的 Releases 頁面下載 school-library-v版本-win-x64.zip。
2. 在 zip 檔上按右鍵 →「解壓縮全部」，放到固定的位置（例如 D:\圖書借閱系統）。
   不要直接在 zip 裡面雙擊執行。
3. 資料會存在同一個資料夾裡，請不要放在會被自動清理的暫存資料夾。

【啟動】
1. 雙擊「圖書借閱系統.exe」。
   第一次執行時，Windows 可能顯示「Windows 已保護您的電腦」：
   請按「其他資訊」→「仍要執行」。這是因為程式沒有購買數位簽章，
   不是病毒。只有第一次會出現。
2. 系統會在背景啟動，並自動開啟瀏覽器。不會出現任何視窗，
   只會在螢幕右下角的工具列（時鐘旁邊）出現一個橘色書本圖示，
   並跳出「圖書借閱系統已啟動」的通知。
3. 第一次執行時，Windows 防火牆可能詢問是否允許網路存取：
   請勾選「私人網路」，再按「允許存取」，手機和平板才能連線。

【右下角工具列圖示】
- 按一下圖示：開啟圖書借閱系統（瀏覽器）。
- 按右鍵會出現選單：
  ．開啟圖書借閱系統
  ．手機／平板連線：顯示讓手機掃描的 QR Code
  ．開啟程式資料夾：資料（bin\）與記錄檔都在這裡
  ．結束服務：關閉系統。結束後電腦、手機、平板都無法借還書
- 找不到圖示時，請按工具列右邊的「^」（顯示隱藏的圖示）。
  想讓圖示一直顯示，可以把它拖曳到工具列上。
- 系統已經在執行時，再雙擊一次「圖書借閱系統.exe」只會開啟瀏覽器。
- 系統無法啟動時會跳出錯誤訊息，詳細記錄在 bin\logs\server.log。

【第一次使用】
1. 用帳號 admin、密碼 admin 登入，系統會要求立刻改成新密碼。
2. 到「管理 → 系統設定」填寫學校名稱。
3. 到「管理 → 班級」建立班級（「純行政」已預先建立）。
4. 到「管理 → 老師帳號」建立每位老師的帳號。
5. 到「新增書籍」掃描書背 ISBN 建檔，再到「列印條碼標籤」印出標籤貼到書上。

【手機／平板連線】
- 手機必須和主機電腦連在同一個 Wi-Fi。
- 在右下角圖示按右鍵 →「手機／平板連線」，用手機掃描畫面上的 QR Code。
  （也可以在系統裡的「管理」或「更多」→「手機／平板連線」找到同一個頁面。）
- 第一次連線會出現「不是私人連線」的警告，選「進階 → 繼續前往」
  （iPhone：「顯示詳細資訊 → 瀏覽此網站」）即可。

【資料與備份】
- 所有資料都在這個資料夾裡的 bin\ 資料夾。
- 系統每次啟動時會自動備份到 bin\backups\（保留最近 10 份）。
- 請定期到「管理 → 備份與還原」下載備份檔，存到隨身碟或雲端硬碟。
- 搬到另一台電腦：把整個資料夾（含 bin\）複製過去即可。

【升級到新版】
1. 在右下角圖示按右鍵 →「結束服務」（結束舊版系統）。
2. 先把舊資料夾裡的 bin\ 整個複製一份到隨身碟，當作備份。
3. 下載新版 zip，解壓縮到新的資料夾。
4. 把舊資料夾的 bin\ 整個複製到新資料夾裡（和新的「圖書借閱系統.exe」放在一起）。
5. 啟動新版。資料會自動升級，帳號、書籍、借閱紀錄都會保留。
- 升級後就不要再用舊版開啟同一份資料；舊版會拒絕開啟較新版本的資料。
- 每一版的變更內容請看 GitHub 的 Releases 頁面。

【USB 條碼掃描槍】
- 一般 USB 掃描槍插上即可使用（模擬鍵盤輸入，掃描後自動按 Enter）。
- 在借書／還書頁面，讓游標停在條碼輸入框，直接掃描即可。
